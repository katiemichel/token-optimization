# Demo 08 - Chronicle and Slash Commands for Usage Optimization

**Time:** ~6-8 minutes  
**Recommended model:** Auto (model-agnostic demo)
**No code changes required.**

This demo highlights low-effort commands that reduce token waste and improve credit efficiency.

## Commands covered

- `/chronicle:cost-tips` - personalized credit and token optimization advice
- `/chronicle:tips` - workflow-level efficiency recommendations
- `/compact` - summarizes old turns to reclaim context space
- `/fork` - branch a side path without polluting your main thread

## The exact prompts to paste

Use these in order.

### Step 1 - Get personalized cost guidance

Open a chat where you've already done a few turns, then paste:

> /chronicle:cost-tips

What to notice:
- Suggestions are based on your recent session behavior.
- This is the fastest way to get practical, personal optimization advice.

### Step 2 - Get broader workflow optimization tips

In the same chat, paste:

> /chronicle:tips

What to notice:
- You get broader usage patterns, not just immediate cost advice.
- Combine with Step 1 for tactical + strategic guidance.

### Step 3 - Compact before switching tasks

After several turns, paste:

> /compact focus on requirements, accepted constraints, and open TODOs only

What to notice:
- Older conversation is condensed to essentials.
- Follow-up prompts are cheaper because less stale context is injected.

### Step 4 - Fork for side exploration

When you want an alternative idea, paste:

> /fork

Then in the forked chat, ask your side question (for example, a different architecture option).

What to notice:
- Main thread stays clean and focused.
- You avoid dragging exploratory branches into your primary implementation context.

## Suggested 90-second comparison exercise

1. Run a task continuation in the original long chat.
2. Run the same continuation after `/compact`.
3. Compare response length, speed, and relevance.

## Key takeaway

Use `/chronicle:*` commands to improve decisions, `/compact` to shrink context, and `/fork` to isolate exploration. These commands often save more credits than changing models alone.
