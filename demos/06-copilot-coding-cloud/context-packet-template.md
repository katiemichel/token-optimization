# Context packet template

## Task
- One-sentence description of the change.

## In scope
- File or directory list.
- Behavioral constraints.

## Out of scope
- Explicit non-goals.

## Known facts
- Tests currently passing/failing.
- Existing conventions to preserve.
- Any prior decisions already made.

## Validation
- `pytest -q`
- `ruff check .`

## Stop condition
- Describe exactly when the agent should stop.
